# Customer Segmentation Analysis Using K-Means Clustering

## 📌 Project Overview

This project applies **K-Means Clustering**, an unsupervised machine learning algorithm, to customer segmentation. The goal is to identify distinct customer groups based on relevant data attributes and explore patterns that can support data-driven business decisions.

## 🎯 Objectives

- Understand customer data through exploratory data analysis.
- Prepare and preprocess data for clustering.
- Apply the K-Means Clustering algorithm.
- Visualize and interpret the resulting customer segments.
- Explore how customer segmentation can support targeted marketing and business strategies.
